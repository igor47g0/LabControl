Endpoints Disponíveis na API

Conexão direta com Spring Boot 3.3 e tratamento de erros padronizado.

POST /equipamentos

Cadastra novo equipamento. Retorno: 201 Created com o JSON criado.

201 Created 400 Bad Request 409 Conflict
GET /equipamentos

Lista todos os equipamentos cadastrados. Retorno: 200 OK com lista JSON.

200 OK
GET /equipamentos/{id}

Busca equipamento por ID. Retorno: 200 OK ou 404 Not Found se inexistente.

200 OK 404 Not Found
PUT /equipamentos/{id}

Atualiza equipamento por ID. Retorno: 200 OK, 404 ou 409 (patrimônio duplicado).

200 OK 400 404 409
DELETE /equipamentos/{id}

Exclui equipamento por ID. Retorno: 204 No Content ou 404 Not Found.

204 No Content 404 Not Found
